# 🆕 New Staff Onboarding Protocol

#Onboarding #Protocol #NewStaff #ViperAssistant

> **This is the standard process Viper Assistant follows when onboarding a new staff member.**

---

## 🎯 When This Applies

This protocol runs when **Cici** or a **Team Lead/Head** asks Viper Assistant to onboard a new staffer.

---

## 📋 The Protocol (Step by Step)

### Step 1 — Send the Staff Guide
As soon as the request comes in, Viper Assistant sends the new staffer the official guide link:

🔗 **https://viperstaffguide.netlify.app/**

The staffer should read through **Start Here** and the relevant **Role** page before anything else.

### Step 2 — Account Creation (Only If Asked)
Viper Assistant will **only** create accounts when explicitly requested ("set up their accounts" / "create logs + planka for them"). Always confirm the following are provided before creating anything:

- ✅ **Discord username / ID** (to link accounts)
- ✅ **Desired login** (for Logs panel)
- ✅ **Planka account name** (usually their Discord display name)

**Accounts to create when asked:**
1. **Logs Panel** — `https://newlogs.viper-roleplay.com/app/login`
   - Create a login/password for them
   - Assign the appropriate access level per their role
2. **Planka** — `https://planka.viper-roleplay.com/`
   - Create a `boardUser` account
   - Add them to the relevant board(s) as `viewer`/`editor` per their team

### Step 3 — Confirm Access & Hand Off
After creation, Viper Assistant:
1. Sends the new staffer their **login details** + the guide link (again, for reference)
2. Notes which teams/boards they've been added to
3. Flags the staffer to complete any 2FA (e.g., Planka Google Authenticator) with the requesting lead

---

## ⚙️ Role-Based Access Cheat Sheet

| Role | Logs Access | Planka Access |
|---|---|---|
| Discord Mod | Read (ticket-relevant) | Viewer |
| Staff Support | Read | Viewer |
| Moderator | Read + rpt tools | Editor (their team board) |
| Admin | Full read | Editor |
| Senior Admin+ | Full read | Editor/Admin |

> _Access levels may be adjusted per team lead instruction._

---

## 📌 Notes

- **Never create accounts proactively** — always on explicit request.
- **Log every onboarding** to the new staffer's user file and to the daily memory log.
- **Guide link is always the first thing sent** — `https://viperstaffguide.netlify.app/`
